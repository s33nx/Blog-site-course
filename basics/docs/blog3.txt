Section 1
Node.js Streams Practice File
=============================

Streams are one of the most powerful features in Node.js. They allow developers to process data piece by piece instead of loading everything into memory at once. This makes streams efficient for handling large files, video processing, network requests, and real-time data transfer.

Readable streams are used when data is being read from a source. Examples include reading a text file, receiving an HTTP request, or downloading data from an API. Writable streams are used when data is being written somewhere, such as saving to a file or sending data to a server.

Transform streams modify data as it passes through them. A transform stream can compress files, encrypt content, or change text to uppercase. Duplex streams support both reading and writing operations.

Node.js includes built-in stream modules that make it easy to work with files and data. The fs module can create readable and writable streams for files. For example, fs.createReadStream() reads data from a file in chunks, while fs.createWriteStream() writes data gradually.

One major benefit of streams is memory efficiency. Instead of loading a massive file into RAM, streams process chunks over time. This is especially useful for applications dealing with logs, media files, backups, and cloud storage systems.

Streams also improve performance. Since data can begin processing immediately, applications become faster and more responsive. Streaming is commonly used in video platforms, music services, and large-scale web applications.

The pipe() method is widely used with streams. It connects a readable stream directly to a writable stream. For example, a file can be copied by piping a readable file stream into a writable file stream.

Backpressure is another important concept in streams. It occurs when data is produced faster than it can be consumed. Node.js stream APIs help manage backpressure automatically, preventing memory overload.

Developers often use streams for:
- Reading large files
- Uploading and downloading files
- Real-time chat systems
- Audio and video streaming
- Data transformation pipelines
- Log processing systems
- Compression and encryption

Streams are event emitters. Common events include:
- data
- end
- error
- finish
- close

Understanding these events is essential when working with streams in real-world applications.
